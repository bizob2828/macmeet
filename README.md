# MacMeet

MacMeet is a small SwiftUI app that runs [Google Meet](https://meet.google.com) in its own
native macOS window instead of a browser tab. It gives Meet a Dock icon, menu bar commands
with keyboard shortcuts, macOS notifications, and the ability to open Meet links clicked in
other apps.

## Features

- A single native window with a compact toolbar: Share, New Meeting, and Join.
- Menu bar commands with keyboard shortcuts (see [Keyboard shortcuts](#keyboard-shortcuts)).
- Join a meeting by code (`abc-defg-hij` or `abcdefghij`) or by full link. If your clipboard
  already holds a Meet link, the Join sheet fills it in for you.
- The Share button copies the meeting link or sends it through the macOS share menu
  (Mail, Messages, AirDrop, and so on).
- A menu bar item for starting, joining, and controlling meetings without the main window.
- Settings for what happens when the main window is closed: quit, or keep running with a Dock
  icon, a menu bar item, or both (see [Settings](#settings)).
- Your Google sign-in is kept between launches.
- Meet notifications (chat messages, requests to join) appear in Notification Center when
  MacMeet isn't the active app.
- Links to sites outside Google open in your default browser.
- Quitting while in a call asks for confirmation first.
- Opens Meet links handed to it by other apps, so a link router such as Finicky can send
  every Meet link to MacMeet (see [Opening Meet links with Finicky](#opening-meet-links-with-finicky)).

## Requirements

- macOS 14 (Sonoma) or later
- Swift 6 toolchain. The Xcode Command Line Tools are enough; Xcode itself is not required.
  Install them with `xcode-select --install`.

## Building and installing

First, create a local code signing certificate. You only need to do this once:

```sh
scripts/make-signing-cert.sh
```

macOS ties camera, microphone, and Screen Recording permissions to an app's code signature.
This script creates a self-signed certificate named "MacMeet Local Signing" in a keychain file
inside the project, `.signing/MacMeet.keychain-db`, so every build has the same signature and
keeps its permissions. Your login keychain isn't touched. `build.sh` adds the project keychain
to the keychain search list only while signing, then restores the list. To start over, delete
the `.signing` folder and run the script again.

Then build:

```sh
./build.sh          # builds build/MacMeet.app
./build.sh --open   # builds and launches it
```

`build.sh` compiles the app with Swift Package Manager, assembles the `.app` bundle with its
`Info.plist` and camera/microphone entitlements, and signs it with the local certificate. If
the certificate is missing, it signs ad-hoc instead and prints a warning; macOS then treats
every build as a new app and asks for permissions again.

To install, copy the app to `/Applications` and launch it once so macOS registers it:

```sh
cp -R build/MacMeet.app /Applications/
open /Applications/MacMeet.app
```

The first time you join a call, macOS asks for camera and microphone access.

If permissions get into a bad state (for example, MacMeet is missing from a list in System
Settings), reset them and relaunch MacMeet so macOS asks again:

```sh
tccutil reset All local.macmeet.MacMeet
```

The app icon, `Resources/AppIcon.icns`, is generated by `scripts/make-icon.swift`. To change
it, edit the script, then regenerate the icon and rebuild:

```sh
swift scripts/make-icon.swift
./build.sh
```

The script also writes a full-size preview to `build/AppIcon-preview.png`.

## Using MacMeet

When MacMeet launches it opens the Meet home page. Sign in with your Google account as you
would in a browser. Sign-in pages from your company's login provider (Okta, for example) open
inside the app.

- **Start a meeting:** click the New Meeting toolbar button or press ⌘N.
- **Join a meeting:** click Join or press ⌘J, then paste a meeting code or link.
- **Share the meeting link:** while in a call, click the Share toolbar button and choose
  Copy Meeting Link or Share, or press ⇧⌘C to copy it.
- **Return to the Meet home page:** press ⇧⌘H.

### Menu bar item

MacMeet adds a camera icon to the menu bar, filled in while you're in a call. Its menu can
open the main window, start or join a meeting, toggle your microphone and camera, copy the
meeting link, and open Settings. The item is always shown while the main window is open; after
the window is closed, it stays only if Settings says so.

### Settings

Open Settings from the MacMeet menu (⌘,) or the menu bar item. Under **When the main window is
closed**:

Closing the main window always ends the current meeting. If you're in a call, MacMeet asks
first.

- **Quit MacMeet:** closing the window quits the app.
- **Keep MacMeet running** (the default): closing the window hides it, and MacMeet waits in the
  background until you reopen the window or a Meet link is opened, which joins that meeting.
  Two options control where MacMeet stays reachable:
  - **Keep icon in the Dock:** click the Dock icon to bring the window back.
  - **Keep item in the menu bar:** use the menu bar item to bring the window back.

  If you turn off the Dock icon, the menu bar item is always kept, so a running MacMeet can't
  become unreachable.

### Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| ⌘0 | Show the main window |
| ⌘N | New meeting |
| ⌘J | Join a meeting |
| ⇧⌘H | Meet home page |
| ⌘D | Toggle microphone (in a call) |
| ⌘E | Toggle camera (in a call) |
| ⇧⌘C | Copy meeting link (in a call) |
| ⌘R | Reload the page |

### `macmeet://` links

MacMeet registers a `macmeet://` link format, which is handy for scripts, Shortcuts, and
launchers:

```sh
open macmeet://new            # start a new meeting
open macmeet://abc-defg-hij   # join a meeting by code
```

## Opening Meet links with Finicky

macOS sends every `https://` link to a single app, your default browser, and has no setting
that routes just `meet.google.com` to a different app. A link router fills that gap: it
becomes your default browser and passes each link to the right app based on rules you write.
[Finicky](https://github.com/johnste/finicky) is a free, open-source link router.

1. Install MacMeet in `/Applications` and launch it once (see
   [Building and installing](#building-and-installing)).
2. Install Finicky, either from its
   [releases page](https://github.com/johnste/finicky/releases) or with Homebrew:

   ```sh
   brew install --cask finicky
   ```

3. Open Finicky and, when prompted, make it your default browser. You can also set it in
   **System Settings → Desktop & Dock → Default web browser**.
4. Create `~/.finicky.js` with the following, replacing `"Safari"` with the browser you
   normally use (for example `"Google Chrome"`, `"Firefox"`, or `"Arc"`):

   ```js
   export default {
     defaultBrowser: "Safari",
     handlers: [
       {
         match: "meet.google.com/*",
         browser: "local.macmeet.MacMeet",
       },
     ],
   }
   ```

   `local.macmeet.MacMeet` is MacMeet's bundle identifier, set in `Resources/Info.plist`. If
   you change it there, change it here too.

5. Click a Meet link in another app, such as a calendar invite, Slack, or Mail. It should open
   in MacMeet, and every other link should open in your usual browser.

To check the routing without Finicky, open a Meet link in MacMeet directly:

```sh
open -a /Applications/MacMeet.app https://meet.google.com/abc-defg-hij
```

If a link that isn't a Meet link reaches MacMeet, it passes the link on to your default
browser.

## Known limitations

- **Google sign-in:** MacMeet identifies itself to Google as Safari, because Google sometimes
  blocks sign-in from embedded web views. If you see "This browser or app may not be secure",
  update the user agent string in `Sources/MacMeet/MeetController.swift`.
- **Screen sharing** is handled by MacMeet rather than WebKit, whose own screen sharing never
  starts in third-party apps. MacMeet shows its own screen and window picker, captures with
  ScreenCaptureKit, and sends the frames to Meet. It needs the Screen Recording permission:
  the first time you present, MacMeet asks for it. Turn MacMeet on in **System Settings →
  Privacy & Security → Screen & System Audio Recording**, then quit and reopen MacMeet.
  Sharing system audio isn't supported.
- **Microphone and camera menu items** work by sending Meet's own ⌘D and ⌘E shortcuts to the
  page. If Meet changes those shortcuts, the menu items stop working.
